# Benchmark（14 例 / 78 字）

`results.csv` 是 2026-11 的批量重绘验收原始数据：14 个用例、78 个字，固定流程、不挑图，逐张人眼核对四项指标；仅“雨夜独行”因多写一个字重跑一次。

| 指标 | 结果 | 口径 |
|---|---|---|
| 一次成功率 | 92.9%（13 / 14） | 字全对 + 不发光 + 无崩坏 |
| 目标字正确率 | 100%（78 / 78） | 逐字计，无缺字错字 |
| 发光率 | 0 / 14 | 无荧光、无外发光、无霓虹 |
| 锚点保留率 | 97.8%（45 / 46） | 仅“大漠孤烟直”丢一缕烟 |

字段说明：

| 字段 | 含义 |
|---|---|
| `chars_ok` | 正确字数的最终结果（含修复后） |
| `glow` | 该图发光区域数量，0 为合格 |
| `anchors_ok` / `anchors_total` | 底图关键锚点在成图中保留的数量 / 应保留数量 |
| `one_shot` | 是否首次出图即合格；`no` 的代表是“雨夜独行”多写一个小“行”，第十七章修掉 |
| `attempts` | 实际出图次数 |

测试设计、判定口径与复跑方式见 [../docs/benchmark.md](../docs/benchmark.md)。批量驱动脚本为 `src/batch_redraw.py`；测试底图未随仓库分发，可用自备照片复跑。
