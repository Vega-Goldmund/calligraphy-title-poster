# 架构：让模型只负责画，不负责想

## 1. 为什么拆成两段

直接把片名丢给绘图模型，它会给你一张有字的图；但它不会替你判断这行字该压在雪上还是雾里，也不会为一个抽象片名决定“该出现什么”。

更现实的是显存：12 GB 卡上，35B 导演的文本编码器约占 8.9 GB，与绘图模型不能同时常驻。因此链路被拆成两段：

```text
片名
  → qwen3.5:35b（Ollama）      读文化、定景、定字、定留白
  → spec.json（结构化设计书）
  → 卸载导演
  → Qwen-Image 2.1 turbo（8 步）
  → 海报
```

导演负责判断，画师负责执行，显存按阶段独占。这不是“多此一举的二次提示词”，而是把审美决策从扩散模型的黑箱里拿出来，变成可检查、可缓存、可复用的数据。

## 2. 设计书里写什么

`director.py` 输出的不是一段自然语言，而是一份 JSON：

```json
{
  "cultural_context": {
    "origin": "二十四节气·惊蛰，春雷始鸣",
    "imagery": "草芽、露珠、湿土、远处闪电"
  },
  "layout": { "layers": "前景虚化草茎 / 中景字 / 远景雨雾", "negative_space": "左上留白" },
  "font_design": {
    "color": "接近白的浅色，压在暗土上",
    "emphasis": "惊字细而高，蛰字重而低"
  },
  "background": { "light": "云隙里的一束冷光", "palette": "冷青、湿土褐" },
  "decoration": { "pinyin": false, "dots": true }
}
```

关键字段：

| 字段 | 作用 |
|---|---|
| `reading` | 导演对片名的理解，供人检查 |
| `cultural_context` | 出处、典故、物候；决定“该出现什么” |
| `layout` | 前中后三层、光源、留白位置 |
| `font_design` | 字色、粗细、哪一笔压重、哪一笔放游丝 |
| `morph` | 字与景如何咬合（如末笔化成稻穗） |
| `background` | 景深、光线、色温 |
| `decoration` | 拼音副标、圆点、印章等 |

导演的取舍标准只有一条：**这个景必须只有这个片名才成立，换个片名还成立就是失败。**

## 3. 三条产线的实现差异

### 文生图 `single`

- 导演出 spec → `single.brief()` 压成短提示词 → `_wf()` 构建 8 步 workflow → 提交并轮询。
- 提示词结构固定：字放最前、完整性硬约束、细劲飞白、缠绕连写。
- 默认单次直接出图，不做逐字质检；`quality.py` 保留为手动旁路。

### 底图重绘 `redraw`

- 一次 Ollama 调用同时完成“读图 + 设计”，35B 只加载一次。
- 读图输出元素清单（人、旗、飞檐、风机、队伍），写进提示词；出图走与文生图完全相同的空 latent 全流程。
- 默认 `recompose`，不是“原图叠字”。`keep` 模式用 VAEEncode + 起始噪声保背景，但字会变弱，只作对照。
- 字色由程序判断：暗底（平均明度 < 0.45）且导演给了高饱和色时，换成接近白的浅色；亮底不动。色名里的“荧光 / 霓虹 / 高亮”会被摘掉，因为这些词一进提示词就诱导光晕。
- 六条硬规则：锚点保留、人物活动保留、光色指纹保留、不加底图没有的元素、留白比例也是构图、断行按语义。

### 透明字层 `alpha`

- 不调导演，提示词自包含狂草约束，所以不抢显存、可复现。
- Qwen-Image 2.1 的 VAE 为四通道，alpha 由模型直接生成，不是事后抠图。
- `tint_alpha()` 保留 alpha、把 RGB 统一着成指定字色，消掉飞白边缘的蓝紫杂色；同时清掉大画布上 alpha < 18 的极淡底色。
- 取舍：字是“贴”上去的，没有环境光交互，默认占满画布、不自动避让留白。

## 4. 四个工程决定

**规格缓存**：同一句片名 + 同一张底图，直接复用设计书。首次 226 s（含 35B 冷启动），命中缓存约 22 s。

**16 像素对齐回裁**：VAE 要求 16 像素对齐，1920×1080 会被算成 1920×1088。落盘前按请求尺寸居中裁回，产物严格等于所需尺寸。

**封闭式逐字核对**：把目标片名告诉 35B，只做“在 / 不在”的逐字判断。开放式 OCR 会漏掉写得轻的字；9B / 12B 会顺着上下文脑补，把缺字判成合格。

**书写视频默认不进主路径**：H3 4/4 通过，单条 110–122 s；但需要额外 44 GB 权重、约 1/4 概率重跑，因此只写进包里，默认不调用。`run.py` 源码中没有视频分支。

## 5. 四个失败实验（为什么现在是这样）

| 实验 | 结果 | 结论 |
|---|---|---|
| 三档 denoise 保底图叠字 | 0.60 无字、0.75 无字且旗变伞、0.90 字不全 | 架构性死结：保背景与写字抢同一份去噪空间 → 改元素驱动重绘 |
| 用 hex 数值控制字色 | `#7EC8E3` → `#87c3d9`，出图不变 | 数值几乎无控制力，改用形态描述（“接近白”） |
| “重墨 / 浓墨”描述 | 字直接变黑 | 毛笔字先验，改用形状语言（“铺开、宽窄、收成细线”） |
| 亮底“整幅只许一个颜色” | 末字整字变白压在雪地上读不出 | 比第一版更糟，已回退；黑白混用写入已知限制 |

完整过程与全部失败记录见 [dev-log.md](dev-log.md)。

## 6. 迁移到别的机器

所有路径、端点、模型名集中在 `src/config.py`，全部可用 `TG_` 前缀环境变量覆盖：

```bash
export TG_COMFY_ROOT=/opt/ComfyUI
export TG_COMFY_URL=http://127.0.0.1:8188
export TG_OLLAMA_URL=http://127.0.0.1:11434
python src/preflight.py --fix
```

工作台默认把仓库根目录当 `TG_SKILL_ROOT`；若使用独立安装的 skill，可显式指定。
