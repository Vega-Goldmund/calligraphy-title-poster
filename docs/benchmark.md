# 测试设计：14 例 / 78 字

## 1. 为什么做这组测试

生成类项目的通病是只展示成功案例。这组测试的目的是把“能不能稳定出图”变成可核对的数据：**固定流程、不挑图、逐张人眼验收；失败不掩盖，重跑次数如实记录。**

## 2. 用例怎么选

14 个用例，2–18 字，刻意覆盖不同难度：

| 类型 | 例子 | 考察点 |
|---|---|---|
| 抽象现代词 | 归途、晚风、雨夜独行 | 没有具体物象时，导演能否给出成立的景 |
| 节气 / 物候 | 惊蛰 | 文化上下文与虚景（闪电） |
| 成语 / 意象 | 潮起潮落、孤灯照海 | 字与景的咬合 |
| 城市夜景 | 万家灯火 | 高楼、窗光等密集锚点 |
| 古诗文 | 高处不胜寒、大漠孤烟直、稻花香里说丰年、当时只道是寻常 | 出处、物候、字形变体 |
| 网络短句 | 人间烟火气最抚凡人心 | 10 字长句的断行与主次 |
| 长标题 | 从流行文化与青年消费看新时代伟大变革 | 18 字硬约束、字号压缩 |

底图统一为 16:9 实拍照片，覆盖山、海、雪、城、雾、沙漠、稻田、雨夜。

## 3. 流程

1. 每例只跑一次 `redraw`，参数固定：8 步、`cfg=1.0`、`recompose`。
2. 出图后不做二次采样、不换 seed、不人工挑图。
3. 逐张核对四项指标，记录到 `benchmark/results.csv`。
4. 仅“雨夜独行”因多写一个字重跑一次（`attempts=2`），其余 13 例均一次通过。

## 4. 指标口径

| 指标 | 判定 |
|---|---|
| **字正确** | 逐字核对：目标片名的每个字都在，无缺字、无错字、无多余字；异体写法可接受 |
| **不发光** | 无荧光、无外发光、无霓虹描边；字边缘允许自然飞白 |
| **锚点保留** | 底图里指定的关键元素（人、旗、飞檐、风机、队伍等）在成图中仍可辨认；虚景（烟、雾、闪电）单独计数 |
| **一次成功** | 首次出图同时满足以上三项 |

## 6. 这组数据不能说明什么

- **不是零样本**：提示词与参数是在更早的十几轮失败实验上收敛出来的；这 14 例是“定型后的验收”，不是“第一次见到就成功”。
- **单一评审**：四项指标由一人核对，没有多人标注与一致性检验。
- **单一硬件**：全部在 RTX 5070 Ti Laptop / 12 GB 上跑，未验证其它显卡的数值稳定性。
- **底图未公开**：测试照片涉及个人素材，未随仓库分发；复跑需自备底图，结果不会完全一致。
- **只测中文**：英文、日文与混合排版未覆盖。

## 7. 怎么复跑

```bash
python src/preflight.py
python src/run.py 归途 --base 你的照片.jpg
```

批量驱动为 `src/batch_redraw.py`，用例格式与 `benchmark/results.csv` 的字段对应；将自备底图与片名填入后即可复跑。请把结果写回 CSV 并保留 `attempts`，否则数据不可比。
